# Security policy

This policy covers ArborACP core and the optional ArborACP adapters package.
Report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/trust-arbor/arbor_acp/security/advisories/new).
Do not disclose vulnerability details in public issues or pull requests.

Please include:

- The affected package version or source commit and relevant runtime/platform details.
- Reproduction steps or a minimal example, including the adapter/CLI version when relevant.
- The potential impact and relevant configuration or logs, with secrets removed.

Use [GitHub issues](https://github.com/trust-arbor/arbor_acp/issues) for other bugs
and feature requests.
